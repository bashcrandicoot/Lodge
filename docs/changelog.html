Changelog

What changed in each release of Lodge, newest first.

Pay what you want.

  1. 1.0.3

    Oct 28, 2026 EDT

    Latest

    Support Lodge now opens Ko-fi.

    • Support Lodge now opens Ko-fi (ko-fi.com/bashframes).
    • That goes for the Lodge and Help menus, the Settings footer and the support note.
    • The README and the website now show Lodge 1.0.3.
    Lodge 1.0.3 on GitHub

  2. 1.0.2

    Oct 27, 2026 EDT

    Choose which days to offload.

    • Date filter. Offload Any date, Today, the Last 7 days or a custom range.
    • Files are judged by when they were recorded.
    • Disk images (.dmg) on a card are now ignored.
    • The installer shows the new Lodge icon.
    Lodge 1.0.2 on GitHub

  3. 1.0.1

    Oct 26, 2026 EDT

    Menu bar mode, a setup guide, and updates from inside the app.

    • Menu bar mode. Lodge can keep running after you close the window, watch for cards and ask to import them.
    • First-launch setup. A short guide to your first preset: destination, folders, naming and safety.
    • A folder for each file type (MP4, WAV, ARW…) inside the last folder. JPG and JPEG share one.
    • Check for Updates in the Lodge menu, plus automatic checks you can turn off in Settings > General.
    • A Support Lodge link, and bashframes contact details in About Lodge and the Help menu.
    • A new app icon, an expandable Layout tree, a progress strip in the offload bar, and a fix for the window title reappearing.

    Coming from 1.0.0? It can’t update itself, so download 1.0.1 by hand once. After that, Lodge updates itself.

    Lodge 1.0.1 on GitHub

  4. 1.0.0

    Oct 26, 2026 EDT

    First public release: offload camera cards with checked copies.

    • Notices cards as you insert them, in a Card, Media, Destination window.
    • Copies only new files. A ledger remembers what was already offloaded.
    • Each file is read back and checked with SHA-256 before it gets its final name. Nothing is overwritten.
    • Folder and file naming templates with a live preview, presets and quick dump.
    • Proxies and sidecars travel with their clip, and videos shorter than 5 seconds stay on the card by default.
    • A Ready to format badge once every file has a checked copy, and card formatting that keeps the file system and name.

    Requires macOS 14 or later. Universal app for Apple silicon and Intel Macs.

    Lodge 1.0.0 on GitHub

Every release, with its downloads, is on GitHub Releases. The full notes are in changelog.md.
