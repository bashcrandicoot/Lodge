Install Lodge 1.0.1

Lodge is a universal app for Apple silicon and Intel Macs. It requires macOS 14 or later. Download Lodge from Gumroad, then open the disk image and drag Lodge to Applications.

Pay what you want.

No account, no analytics, and copying never uploads anything. The only time Lodge goes online is a daily check for updates, which you can turn off in Settings > General.

macOS 15 Sequoia and later

  1. Open Lodge.
  2. Click Done on the warning.
  3. Go to System Settings > Privacy & Security.
  4. Click Open Anyway next to Lodge, and confirm.

macOS 14 Sonoma

  1. Right-click or Control-click Lodge.
  2. Choose Open.
  3. Choose Open again.

Lodge is not notarized, which is why macOS asks.

The first time Lodge reads a card, allow access to files on a removable volume. Building from source is in the contribution guide. The user guide, FAQ, and changelog live in the repository.
