What is Lodge?

Lodge is a media ingest tool for creators. When you plug in a camera card or drive, it asks Import with Lodge?, recognizes the folders most cameras use, and remembers which camera you used with each card. Presets save your destination, folder and file templates, camera, and file rules. Tokens such as {date}, {project}, {camera}, and {seq} shape the folder path and file names. Each offload can filter by file type or date, and skip short clips. Favorite destinations can sit on different drives. Offload into a project folder, or use Quick dump to put footage from different days into a dated folder. Save the setup as a preset and the next shoot is one click.

Only what is new

Lodge remembers what it already copied and brings over only new files.

Verified, never overwritten

Lodge writes each file, reads it back, and checks it with SHA-256. A match is renamed to the final name. A mismatch is deleted.

  • The card is only read. A file already at the final path is not overwritten.
  • If nothing is new, Lodge says why: a missing copy, a skipped short clip, or the date filter. Otherwise you'll see Everything on this card is already offloaded.
  • Ready to format shows only when every file on the card has a verified copy.
  • If a copy is missing, choose Re-offload.

Install Lodge 1.0

Lodge is a universal app for Apple silicon and Intel Macs. It requires macOS 14 or later. Open the .dmg, and drag Lodge to Applications.

Try for Freefor Mac

No account, no analytics, and copying never uploads anything. Lodge goes online for a daily update check, which you can turn off in Settings > General.

Lodge isn't notarized, so the first time, right-click Lodge and choose Open, or go to System Settings > Privacy & Security > Open Anyway.

macOS 15 Sequoia and later

  1. Open Lodge.
  2. Click Done on the warning.
  3. Go to System Settings > Privacy & Security.
  4. Click Open Anyway next to Lodge, and confirm.

macOS 14 Sonoma

  1. Right-click or Control-click Lodge.
  2. Choose Open.
  3. Choose Open again.
